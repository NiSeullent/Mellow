02 /선택한 버전 설치
# 바이너리 릴리스 확인 중

바이너리가 아직 게시되지 않았다면 Releases에서 개발 소스와 검증 기록을 확인할 수 있습니다.

kext 설치와 실기 검증은 어떻게 진행하나요?

기본 설치는 시스템 kext를 변경하거나 GPU 검증을 실행하지 않습니다. /Library/Extensions 복사는 --install-kext, 필요한 Lilu 설치는 --install-dependencies, 표준 kmutil 준비는 --prepare-kext를 명시적으로 선택한 경우에만 진행합니다. 자동 재부팅이나 보안 설정 변경은 하지 않습니다. 이 절차의 성공도 Metal·WindowServer 가속 지원의 증거가 아닙니다.
